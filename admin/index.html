Moderator

The queue.

Submission triage. Auth-gated. Fetches pending submissions from the OSEA backend, shows detection overlays, and lets approved moderators accept / reject / request more info.

§ I Backend status

Backend not yet deployed.

The moderator queue activates once the Flask API ships at api.oseascience.com (or its development URL). Until then, this page is a stub. Submissions made via the public form are stored in browser session storage as a local preview.

§ II When the backend is live

Pending submissions render here as field-note cards: thumbnail, detection overlay (body / head / spots), EXIF, submitter info, and three actions:

Accept moves the photo into the catalogue and the row becomes a normal tagging target.

Reject moves the file to a 30-day soft-delete buffer, with a reason recorded for the rejection email.

Needs Info sends the submitter a follow-up question (V2 once email is wired in).
